# 立绘 / 动作帧工具

把画好的立绘变成桌宠能用的动作帧。

## 11 个动作

| 动作名 | 什么时候用 |
|---|---|
| `start` | DSH 一轮开工 |
| `working` | DSH 正在思考（常驻） |
| `tool_pwsh` | 敲命令 |
| `tool_edit` | 改代码 / 写文件 |
| `tool_read` | 读文件、搜索 |
| `tool_web` | 上网搜索、抓网页 |
| `approval` | 有工具等你批准 |
| `error` | 工具报错 |
| `done` | 一轮结束 |
| `idle` | 静默超过 120 秒 |
| `sing` | 音乐播放中 |

**没画图的动作会自动用三视图兜底，不会报错。** 所以可以先只画几个试试。

## 用起来

### 1. 准备图

- **纯白底**（脚本会自动抠掉）
- 立绘完整，**别裁到边**
- PNG / JPG 都行

### 2. 命名

任选一种，脚本自动识别：

```
approval.png          动作名.png        → 第 1 帧
approval-1.png        动作名-序号.png   → 第 N 帧
approval_1.png        动作名_序号.png   → 第 N 帧
start-work1.png       ← start 第 1 帧的写法
```

同一个动作给多张（`-1` `-2` `-3`）就会**循环播放**；只给 1 张就是**静态显示**。

### 4. 跑脚本

```bat
python make_frames.py
```

需要 Python 3 和 Pillow：`pip install pillow`


## 脚本做了什么

| 步骤 | 说明 |
|---|---|
| ① **泛洪抠白底** | 只抠「连到画布边缘」的浅色区域。**人物内部的白色（脸、头饰）不会被误删** —— 这是和"按颜色阈值抠图"的本质区别 |
| ② 裁到角色 | 量出角色实际尺寸 |
| ③ **统一缩放** | 角色高度 = 画布高 × 0.95。所有动作一致 → **切换时不会跳大小** |
| ④ 生成三档 | 特小 122 / 中 245 / 大 306 |

画布宽度按**最宽的那个动作**统一，保证张开手臂也不会被裁。

`sing` 用「贴紧画布」（它人物瘦，统一宽画布会白占地方）。

## 调参数

脚本顶部：

| 常量 | 作用 |
|---|---|
| `FLOOD_TOL` | 泛洪容差（默认 40）。背景不干净就调大 |
| `CHAR_RATIO` | 角色占画布高的比例（默认 0.95） |
| `TIERS` | 三档显示高度 |
| `TIGHT_CANVAS` | 哪些动作用贴紧画布 |

## 诊断

跑完会在同目录生成 `生成报告.txt`，里面有：

- 每张源图的**角色尺寸和宽高比**
- 各档的**画布尺寸**
- 每个动作**现在有几张图**

**哪张图显示偏小？** 看报告里的宽高比 —— 比别的动作小说明人物偏瘦，
正常（因为高度是统一的）。想单独放大的话，改 `桌宠.py` 里的：

```python
DSH_ACT_ZOOM = {"sing": 1.18}
```

> ⚠️ 别调太大：放歌时上方正在显示歌词气泡，人物头顶太高会盖住歌词。
